Compound Measures Formula Reference

GCSE Standard
1. Speed (S, D, T) S = D / T
\(S = \frac{D}{T}\)
\(D = S \times T\)
\(T = \frac{D}{S}\)

Time conversion: \(36\text{ mins} = \frac{36}{60} = 0.6\text{ hrs}\)

Unit multiplier: \(1\text{ m/s} = 3.6\text{ km/h}\)

2. Density (D, M, V) D = M / V
\(D = \frac{M}{V}\)
\(M = D \times V\)
\(V = \frac{M}{D}\)

Metric conversion: \(1\text{ g/cm}^3 = 1000\text{ kg/m}^3\)

Composite Density: \(\frac{\text{Total Mass}}{\text{Total Volume}}\)

3. Pressure (P, F, A) P = F / A
\(P = \frac{F}{A}\)
\(F = P \times A\)
\(A = \frac{F}{P}\)

Force calculation: \(\text{Weight } (F) = \text{mass } (m) \times g\)

Standard unit: \(1\text{ N/m}^2 = 1\text{ Pascal (Pa)}\)

4. Rate of Flow (R, V, T) R = V / T
\(R = \frac{V}{T}\)
\(V = R \times T\)
\(T = \frac{V}{R}\)

Volume unit: \(1\text{ m}^3 = 1000\text{ litres} = 1,000,000\text{ cm}^3\)

Pipe flow: \(\text{Rate} = \text{Area } (\pi r^2) \times \text{Velocity}\)
